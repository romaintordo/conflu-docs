# Connectors

Conflu supports the following connectors. Each connector adds a set of MCP tools that Claude can use.

## Live

### Microsoft 365
Connect your M365 account to access Outlook, OneDrive, Teams, and SharePoint.

**Available tools:** `outlook_search_emails`, `outlook_get_calendar`, `outlook_list_contacts`, `onedrive_search_files`, `teams_list_messages`

**Auth:** OAuth 2.0 (Microsoft Entra ID). Tokens are refreshed automatically.

### Google Workspace
Connect your Google account to access Gmail and Google Calendar.

**Available tools:** `google_search_gmail`, `google_list_calendar_events`, `google_get_email`

**Auth:** OAuth 2.0 (Google). Gmail is in Testing mode — tokens expire after 7 days until Google production verification is approved.
