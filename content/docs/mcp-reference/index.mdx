# MCP Tool Reference

All tools follow the [Model Context Protocol](https://modelcontextprotocol.io) standard. Each tool is called by Claude automatically based on your query.

## Microsoft 365

### `outlook_search_emails`
Search emails in your Outlook inbox.

**Parameters:**
- `query` (string, required) — Search query (supports Outlook search syntax)
- `maxResults` (number, optional) — Max number of results (default: 20)
- `folder` (string, optional) — Folder name (default: Inbox)

**Example prompt:**
> "Find emails from Sarah about the Q3 report"

---

### `outlook_get_email`
Get the full content of a specific email.

**Parameters:**
- `id` (string, required) — Email ID (from search results)

---

### `outlook_get_calendar`
Get calendar events for a date range.

**Parameters:**
- `startDate` (string, required) — ISO 8601 date
- `endDate` (string, required) — ISO 8601 date
- `maxResults` (number, optional) — Max results (default: 50)

---

### `onedrive_search_files`
Search files and documents in OneDrive.

**Parameters:**
- `query` (string, required) — Search query
- `fileType` (string, optional) — Filter by type (e.g. "docx", "pdf", "xlsx")
- `maxResults` (number, optional) — Max results (default: 20)

---

## Google Workspace

### `google_search_gmail`
Search emails in Gmail.

**Parameters:**
- `query` (string, required) — Gmail search query
- `maxResults` (number, optional) — Max results (default: 20)

---

### `google_list_calendar_events`
List Google Calendar events.

**Parameters:**
- `startDate` (string, required) — ISO 8601 date
- `endDate` (string, required) — ISO 8601 date
- `calendarId` (string, optional) — Calendar ID (default: primary)

## Rate Limits

| Plan | Requests/month |
|------|---------------|
| Free | 50 |
| Pro | 500 |
| Ultra | 5,000 |

Requests that exceed the limit return a `429 Too Many Requests` error with a message explaining the limit.
