# Security and data

Conflu is designed so provider content passes through without being kept on disk. For the full legal and policy text, use the marketing site — this page is a short technical summary.

## Official policies

- [Your data](https://conflu.xyz/data) — what we store and what we do not
- [Security](https://conflu.xyz/security) — tokens, infrastructure, EU processing
- [Privacy policy](https://conflu.xyz/privacy)

## Tokens

OAuth refresh tokens live in **Google Cloud Secret Manager**, one secret per account. They are not stored in Firestore. Disconnecting an account deletes the secret.

## MCP request metadata

Conflu logs **metadata** about each tool call (tool name, account id, latency, status, egress size) for the dashboard request log. It does **not** store tool arguments, tool results, email bodies, or attachment content in that log.

## API keys

Your MCP API key (`cfx_…`) is a bearer credential. Treat it like a password. Rotate it from **MCP setup** if it leaks.

## Reporting issues

Security concerns: see the contact section on [conflu.xyz/security](https://conflu.xyz/security).
