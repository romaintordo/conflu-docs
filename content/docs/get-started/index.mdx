# Getting started

Conflu is multi-account MCP middleware: you add **one** HTTP endpoint to your AI client, connect **many** mailboxes (Microsoft 365 and Google Workspace today), and pick the account per tool call with `account_id`. You do not reconfigure Claude or Cursor for each client.

## What you need

- A [Conflu account](https://conflu.xyz/signup)
- An AI client that supports MCP over HTTP (Claude Desktop, Claude Code, Cursor, and others)
- A Microsoft 365 or Google Workspace mailbox you can sign in to with OAuth

## 1. Create your account

Sign up at [conflu.xyz](https://conflu.xyz/signup). You start on the Free plan with package connectors (Microsoft 365 and Google Workspace).

## 2. Connect your first mailbox

1. Open the dashboard → **Connections** → **Accounts**.
2. Click **Add Microsoft 365 account** or **Add Google account**.
3. Complete the provider sign-in. Conflu stores only the refresh token in Google Cloud Secret Manager — not in Firestore.

Reconnecting the same email updates the same account record; Conflu does not create duplicates.

## 3. Get your MCP API key

1. Go to **Connections** → **MCP setup**.
2. If you do not have a key yet, connect an account (a key is minted on first successful OAuth) or use **Rotate key**.
3. Copy the key once — it is shown in full only at mint time (`cfx_…`).

Your MCP endpoint URL is:

```
https://mcp.conflu.xyz/v1
```

Every request uses `Authorization: Bearer cfx_YOUR_KEY`.

## 4. Connect an AI client

Follow [Connect your AI client](/docs/connect-ai-client) for Claude Desktop, Claude Code, Cursor, and other hosts.

## 5. Run a first tool call

After the client lists tools, ask it to list mail — or call `microsoft_list_emails` yourself with JSON-RPC:

```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "tools/call",
  "params": {
    "name": "microsoft_list_emails",
    "arguments": {
      "account_id": "YOUR_ACCOUNT_ID",
      "folder": "inbox",
      "limit": 5
    }
  }
}
```

Post that to `https://mcp.conflu.xyz/v1` with your bearer token. You get message metadata back from Microsoft Graph (not full bodies on all plans).
